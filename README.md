# matt-kramer

A single-page tribute site for **Matt Kramer** — Harvard '08, Red Sox '11 (catcher converted to 95-mph pitcher), Rush Medical, healthcare AI at SteriCUBE, co-founder of Show-Me Strength, and the person who handed Gordon Darby alive and ready.

Merged 2026-05-10 from two prior drafts: the baseball-card frame (with the flip-card mechanic, polaroid front + Topps reverse, career table) and the loving-report frame (Two Gifts of 2026 + 5-point Partnership list).

Built by Gordon Bellamy. One self-contained `index.html` — no build step, no framework. iPhone-first responsive.
